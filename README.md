## GitHub Pages (separate repository)

1. Create a repository named `portfolio` and upload the contents of this folder to its root.
2. In Settings → Pages, choose **Deploy from a branch**, `main`, `/ (root)`.
3. The expected address is https://saltypal.github.io/portfolio/ . This is a proposed address, not a verified published site.
4. If you use another repository name or domain, update `navigation.portfolioUrl` in the separate Website project's `site.config.mjs`.
